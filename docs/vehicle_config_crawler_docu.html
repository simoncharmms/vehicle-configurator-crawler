How It Works

Playwright-based crawlers collect model, option, and price data. Python processing normalizes brand-specific names, stores dated JSON snapshots, and publishes the dashboard through GitHub Pages. GitHub Actions runs the collection workflow daily at 06:00 CET.

Current Limitations

  • Audi has no extracted vehicles because its endpoints remain blocked by HTTP 403 protection.
  • Mercedes-Benz has no newer option prices after 2026-09-08 because subsequent crawls returned HTTP 403.
  • Not every tracked option has a numeric price; several brands currently provide vehicle data without priced options.
  • The dashboard stores daily snapshots, not continuous real-time price changes.
