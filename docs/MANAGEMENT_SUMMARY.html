Vehicle Option Price Tracker

Automated Vehicle Configurator Monitoring & Analysis Platform

Executive Summary: This project automates the extraction, standardization, and analysis of vehicle option pricing from major German automotive configurators (Mercedes-Benz, Audi, Porsche). It provides real-time pricing visibility into automotive options across brands, enabling pricing strategy analysis and market comparison.

Project Goal

Automatically monitor and track vehicle option pricing across multiple premium automotive brands to provide:

  • Cross-brand option price comparison (same feature, different brands)
  • Option standardization across brands (e.g., "4MATIC" = "Quattro" = "xDrive" = AWD)
  • Historical price tracking and trend analysis
  • Automated daily data collection and reporting
  • Accessible web-based dashboard for stakeholders

High-Level Architecture

The system consists of four primary components working in concert:

1. Data Collection Layer (Python/Playwright)

Automated crawlers that extract vehicle data from configurator websites:

  • Browser-based scraping using Playwright (modern, JavaScript-capable)
  • Multi-brand support: Mercedes-Benz, Audi, Porsche (easily extensible)
  • Resilient error handling: automatic retries, graceful fallbacks, detailed logging
  • Option extraction from product pages with price capture

2. Data Processing & Standardization (Python)

Normalize brand-specific option names and aggregate pricing data:

  • Option mapping database (100+ brand aliases -> 15 standardized categories)
  • Cross-brand price aggregation and statistical analysis
  • Historical data preservation for trend analysis
  • JSON-based data storage (human-readable, version-controllable)

3. Automation & Deployment (GitHub Actions)

Scheduled execution and continuous deployment:

  • Daily automated crawls at 6:00 AM CET
  • Automatic commit of new data to repository
  • Continuous deployment of dashboard updates
  • No manual intervention required

4. Data Visualization (Web Dashboard)

Real-time, interactive price comparison interface:

  • HTML5 responsive design (mobile-friendly, no backend required)
  • Cross-brand option pricing comparison table
  • Price distribution charts and trends
  • Category-based filtering and sorting
  • Hosted on GitHub Pages (free, reliable, auto-updating)
System Data Flow: Vehicle Configurator Websites | v Playwright Browser Engine | v Data Extraction (model/option/price) | v Option Name Normalization | v JSON Data Storage (git-tracked) | v GitHub Pages Dashboard | v Web Interface (Live, Updated Daily)

Key Benefits

  • Automation: No manual data collection required. Daily crawls at 6 AM CET.
  • Standardization: Cross-brand comparison made possible via option name normalization.
  • Accessibility: Real-time web dashboard, no special software required.
  • Resilience: Automatic retry logic, graceful error handling, historical fallbacks.
  • Scalability: Framework easily extends to additional brands and options.
  • Transparency: All code and data tracked in git, transparent history and changes.

Current Status

Production Ready
  • Mercedes-Benz extraction: Operational
  • Option price database: 15 standardized categories with 100+ brand aliases
  • Dashboard: Live and updated automatically
  • GitHub Actions: Scheduled daily at 6:00 AM CET
Known Limitations
  • Audi and Porsche: Currently blocking scrapers (HTTP 403). System falls back to reference pricing.
  • Option extraction: Live option data limited; system uses reference database for all options.
  • Dynamic pricing: Real-time price updates not captured; daily snapshots only.

Future Roadmap

  • Implement proxy rotation to bypass Audi/Porsche blocks
  • Advanced option extraction from individual model configuration pages
  • Historical trend analysis and price forecasting
  • Email reports with pricing alerts
  • Export data to Excel/CSV for external analysis
  • Integration with internal pricing systems
